# Vrinda Store Annual Report 2022 – Excel Data Analysis

## 📌 Project Overview
This project focuses on analysing Vrinda Store's 2022 sales data using Microsoft Excel. An interactive dashboard was developed to understand sales performance, customer demographics, order status and sales channels.

## 🎯 Project Objectives
- Analyse monthly sales and order trends.
- Compare sales between men and women.
- Understand customer age and gender distribution.
- Analyse order delivery and cancellation status.
- Identify the top-performing states.
- Compare sales across different shopping channels.
